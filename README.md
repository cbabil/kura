# StraturaOS

StraturaOS is a custom operating system designed for the Raspberry Pi 5, built on the Yocto Project. It offers robust container support, over-the-air (OTA) updates, and advanced device management capabilities, making it ideal for IoT and edge computing applications.

## Features

- **Yocto-based**: Lightweight and customizable Linux distribution.
- **Container Support**: Integrated Docker runtime for containerized applications.
- **OTA Updates**: Secure and reliable over-the-air update mechanism using RAUC.
- **Advanced Security**: SELinux, AppArmor, and TPM integration for enhanced security.
- **Network Management**: Flexible network configuration with failover support.
- **Device Management**: Comprehensive device monitoring and management tools.
